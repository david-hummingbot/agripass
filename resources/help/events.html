Event lifecycle

Every event moves through four stages, always in this order:

StageWhat happensButton to move on
DraftBeing prepared. Not visible to the public.Publish event
ActiveRegistration is open (if it is the active event) and scanners can check people in.Mark as completed
CompletedRegistration and scanning are closed. Attendance is final, so certificates can be issued.Archive event
ArchivedPermanently locked for PRC/CPD audits. Everything can still be viewed and exported.None

Stages cannot be reversed. Archive an event only when certificates and payments are final.

1. Create the event

  1. Choose New Event in the sidebar.
  2. Fill in the title, event type, venue, dates and description.
  3. Set the Fee. Use 0 for free events. Free registrations are marked Waived automatically, so their passes work straight away.
  4. Under CPD, enter the CPD units, the Minimum attendance for certificate (percentage of sessions, 80% by default) and the PRC accreditation no.
  5. Enter the certificate signatory's Name and Position, as they should appear on certificates.
  6. Save. The event starts as a Draft.

2. Add sessions

Sessions are the parts of the event that are scanned separately, for example "Day 1 Morning Plenary" and "Day 1 Afternoon Technical Track". On the event's Sessions tab, use Add session for each one, with its date and start and end time.

CPD eligibility counts sessions. With four sessions and an 80% requirement, attendees must attend all four, because three of four is only 75%. Plan the number of sessions and the requirement together.

Deleting a session also deletes its attendance records.

3. Add registration questions (optional)

On the Registration form tab, Add field adds a question to the form, such as T-shirt size or dietary needs. Field types are Text, Number, Dropdown (with your list of options) and Checkbox, and each can be required or optional. Answers appear in the registration list, the exports and the Reports tab.

4. Open registration

  1. Click Publish event to make it Active.
  2. Click Set as active event so it appears on the public registration page and becomes the default for scanners.
  3. Share the registration link: {{APP_URL}}/

Only one event can be the active event. Making a new event active takes the previous one off the registration page, but scanners can still choose any Active event.

5. After the event

  1. Make sure every scanner has synced (no scans waiting on any device).
  2. Click Mark as completed.
  3. Issue certificates (see CPD certificates) and download reports.
  4. When everything is final, click Archive event.
